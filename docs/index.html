Full CLI Reference

Scriptable. Expressive. Powerful.

Everything you can do in the TUI is also available as a high-speed CLI flag.

Adding Tasks todo add
$ todo add "Learn DSA"
$ todo add "Fix Auth" --priority high --due-date 2026-10-31
$ todo add "Ship App" --tag study --tag coding -d "Arrays practice"
List & Powerful Filtering todo list
$ todo list --overdue
$ todo list --status active --priority high --sort due
$ todo list --tag study --due-before 2026-12-31
Task State Transitions done / undo / delete
$ todo complete <id> # or: todo done <id>
$ todo uncomplete <id> # or: todo undo <id>
$ todo delete <id> # remove permanently
Search & Insights search / count / view
$ todo search "critical"
$ todo count # total, active, completed, overdue
$ todo view <id> # inspect full card with timestamps
