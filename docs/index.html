Architecture

Engineered for pure speed.

Zero unnecessary abstractions. Just native Node.js and local disk I/O.

Vim & Arrow Key Navigation

Navigate your task backlog without taking your fingers off home row. Move with j / k, complete items with Space, and search instantly with /.

j / k Space Enter / f (filter) s (sort)

Atomic JSON Writes

Zero corrupted databases. Records are written to temp files and swapped atomically via the filesystem.

✓ Safe atomic rename
✓ Plain text JSON portability

Dual Personality

Run todo for the full interactive Ink TUI, or pipe commands to grep, awk, and shell scripts.

$ todo list --overdue | wc -l

CLI Specification

Expressive command line syntax.

Task Creation
Add tasks with optional metadata
$ todo add "Learn DSA"
$ todo add "Fix Auth" --priority high -D 2026-10-31
Listing & Querying
Filter by status, tag, or due dates
$ todo list --overdue
$ todo list --status active --priority high
State Mutations
Complete, reopen, or remove tasks
$ todo complete <id> # or done
$ todo delete <id>
Search & Metrics
Instant grep and backlog summaries
$ todo search "auth"
$ todo count
